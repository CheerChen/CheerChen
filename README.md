## 📦 Projects

### ✨ Events

- [**art-calendar-tokyo**](https://github.com/CheerChen/art-calendar-tokyo) — Tokyo art exhibition calendar, LLM-powered scraper → [art-calendar-tokyo.pages.dev](https://art-calendar-tokyo.pages.dev)
- [**nana.live.acc**](https://github.com/CheerChen/nana.live.acc) — Nana Mizuki live concert database, setlists, tours, and analytics → [nana-live-acc.pages.dev](https://nana-live-acc.pages.dev)

### 📺 webOS TV

- [**decotv-webos**](https://github.com/CheerChen/decotv-webos) — DecoTV LG webOS client, Douban catalog, multi-source speed test, full remote navigation, hardware-decoded playback
- [**navidrome-stage-webos**](https://github.com/CheerChen/navidrome-stage-webos) — Immersive lyrics stage on LG webOS TV, per-character sync, connects to self-hosted Navidrome
- [**webos-tv-kit**](https://github.com/CheerChen/webos-tv-kit) — Shared platform layer and device tooling for webOS TV apps

### 🤖 Developer Tooling

- [**ctxd**](https://github.com/CheerChen/ctxd) — turn work URLs into LLM-ready Markdown; exports GitHub PRs, Slack threads, Confluence pages, and Jira issues
- [**TideTab**](https://github.com/CheerChen/tidetab) — Chrome new tab that ranks your Jira issues, GitHub PRs, and Confluence pages from local browsing history  
  <a href="https://chromewebstore.google.com/detail/tidetab/hpgpcibggjcpfcifddfcbpakbfojiaef"><img src="assets/chrome-web-store-badge.png" alt="Available in the Chrome Web Store" height="40"></a>
- [**session-index-viewer**](https://github.com/CheerChen/session-index-viewer) — local web viewer to browse and resume Claude Code & Codex CLI sessions
- [**pi-extensions**](https://github.com/CheerChen/pi-extensions) — extensions for the [pi](https://pi.dev) coding agent: warns when a model overthinks, shows subscription quota in the status bar

### 🥽 VR

- [**PasteToPlay**](https://pastetoplay.app) — VR video player for Meta Quest. Paste a link, it just plays. Auto-detects VR180/360/SBS/TB/fisheye from the actual frames  
  <a href="https://www.meta.com/experiences/pastetoplay-180360-vr-video-player/1231909206675936/"><img src="assets/badges/meta-horizon-store.svg" alt="Download on Meta Horizon Store" height="40"></a>
